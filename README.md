# 모션 룰렛

카메라 동작으로 경품 룰렛을 돌리는 정적 웹앱입니다. 이름 입력 없이, 룰렛·선물 목록·모션 카메라를 중심으로 구성했습니다.

## 실행

Windows에서는 `start-preview.cmd`를 실행합니다. Python 3가 필요하며 브라우저가 `http://127.0.0.1:4175/#draw`로 열립니다. 터미널은 켜 두세요.

직접 실행: `python tools/serve.py` (브라우저를 열지 않으려면 `--no-open`). 또는 `python -m http.server 4173 --bind 127.0.0.1`로 실행하고 localhost 주소를 엽니다.

`file://`에서는 카메라 모델을 불러올 수 없습니다. 카메라 기능은 localhost 또는 HTTPS에서 사용합니다. 별도 백엔드·데이터베이스·빌드·npm 설치는 필요하지 않습니다.

## 사용

1. 설계 화면에서 상품명·개수·행사명을 정합니다. 동작은 정해진 순서로 진행합니다.
2. 추첨 화면에서 카메라 연결을 누르고 권한을 허용합니다.
3. 화면 가운데에 상체를 맞추고 2초 기다리면 동작 안내가 자동으로 시작됩니다.
4. 먼저 안내된 상체 자세를 1초 유지합니다. 양손 높이 들기·양팔 벌리기·한 손 높이 들기·양팔로 큰 하트 만들기가 회차마다 차례로 나옵니다. 성공하면 손 돌리기 안내로 넘어갑니다. AR 노란 손잡이에 한 손을 0.25초 멈춘 뒤 한 방향으로 한 바퀴(360도) 돌립니다. 손을 움직이는 동안 원판도 같은 방향으로 따라옵니다. 이 단계는 반대 팔과 양 팔꿈치가 보이지 않아도 됩니다. 자세만 완성해서는 추첨이 시작되지 않습니다.
5. 원판 회전 → 감속 중 상단 포인터가 자연스럽게 확대 → 경계에서 좌우 흔들림 → 완전 정지 → 당첨 결과 순서로 진행합니다.
6. 결과 팝업은 등수별 새싹 캐릭터·등수·상품명과 확인 버튼으로 표시합니다. 1~10등은 각기 다른 표정·동작을 쓰고 11등 이상은 10등 이미지를 사용합니다. 확인을 누르면 다시 2초 위치 확인부터 자동으로 준비합니다. 수동 추첨도 제공합니다.

한 명씩, 밝은 곳에서 머리·어깨·양팔이 화면에 들어오도록 서 주세요. 골반이나 하체는 보이지 않아도 됩니다. 동작 속도나 방향은 당첨 확률을 바꾸지 않습니다. 손을 돌린 방향은 원판의 회전 방향에 반영합니다.

## 구현 범위

- 남은 상품 개수에 따른 조각 크기·확률, 경품 편집과 자동 저장.
- 실제 카메라 영상, 거울 화면에 팔 관절·안내 원·진행률 표시.
- MediaPipe Tasks Vision 1.2.2와 Lite Pose 모델을 앱에 동봉하여 브라우저 안에서 분석. 앱은 영상을 녹화·업로드하지 않습니다.
- 위치 확인·자세·원호의 한 순서당 한 회차, 회전 중 입력 차단, 기록 창에서 인식 중지, 화면 이탈 시 카메라 종료.
- 마지막에는 경계 근처에서 작은 진폭으로 좌우 정착하며, 확대창은 원래 상단 포인터를 덮고 원판과 같은 각도로 움직인 뒤 결과를 발표합니다. 중단 회차 복구와 한 번만 재고 차감.
- 제목은 학교안심 포스터, 나머지는 케리스 배움체. A안 연구회 로고와 생성한 안내 이미지 적용.

설정과 기록은 해당 브라우저 기기에 저장됩니다. 동시 운영·여러 기기 재고 공유·운영자 계정·서버 감사 기록은 별도 서버/DB 연동 범위입니다. 색상 직접 편집, CSV/JSON 내보내기, 사운드는 아직 구현하지 않았습니다.

## 검증과 문서

`node --test tests/*.cjs`: 계산·동작 판정·카메라 수명 주기 41개 테스트.

실제 인식 엔진은 가상 카메라 영상으로 실행했고, 두 모션의 추첨 연결은 관절 좌표 재생으로 검증했습니다. 실물 카메라의 행사장 인식률은 아직 측정하지 않았습니다.

## 듀얼 모니터

추첨 화면의 카메라 새 창 버튼으로 같은 영상·관절 표시·AR 손잡이를 별도 창에 표시한다. 카메라 아래에 목표 동작 그림·설명·진행률이 표시되며 카메라 연결과 전체화면 버튼을 제공한다. 새 창을 다른 모니터로 옮기고 전체화면을 누른다. 원래 화면은 룰렛을 크게 보여 주며 룰렛 전체화면 버튼도 제공한다. 카메라 창을 닫으면 원래 배치로 복귀한다. 카메라와 모델은 한 번만 열고 새 창은 결과를 공유한다. 새 창의 프레임 시계로 추적을 계속하며 원래 탭을 닫으면 카메라 창도 닫는다. 브라우저 팝업 차단 시 허용 안내를 표시한다.


운영자 1등 모드: 연구회 로고·명칭 영역을 0.9초 이내 간격으로 연속 5번 누르면 배경이 옅은 붉은색으로 바뀐다. 활성 상태에서 한 번 더 누르면 취소된다. 실제 다음 추첨 한 회차에만 남아 있는 1등 상품을 선택하고 즉시 모드를 해제하며, 기존 감속·경계 확대·결과·재고 처리 경로를 그대로 사용한다. 1등 소진 시 활성화하지 않는다. 회전 중 클릭은 무시하며 새로고침하면 모드는 해제된다. 일반 모드의 수량 비례 추첨은 유지한다.


카메라 분리 창에도 본 화면의 결과 팝업과 동일한 등수별 캐릭터·등수·상품명을 표시한다. 회전 종료 후 본 화면 결과가 열릴 때만 함께 열며, 어느 쪽의 확인 버튼으로도 두 결과창을 함께 닫는다. 모바일 상단은 모션 룰렛과 연구회 로고·명칭을 작은 크기로 좌우 한 줄에 배치하고 탭은 다음 줄에 둔다. 손잡이 이미지의 원형 중심축은 카메라 정중앙이며 같은 손으로 한 바퀴를 완료해야 본 추첨이 시작된다.

팔 하트 판정은 골반 높이 대신 어깨 간격을 기준으로 한다. 이마 부근에서 손을 모으고 팔꿈치를 둥글게 벌린 모양을 유지하되, 양손 높이 차이·낮거나 높은 팔꿈치·일부 손목 신뢰도 저하를 허용한다. 손만 모은 손가락 하트나 가슴 앞 포즈는 구분한다. 한 바퀴 손잡이 동작은 반대 손이나 팔꿈치를 요구하지 않으며 최대 12초 안에 같은 방향 360도를 누적한다. 작은 반경 변화는 허용하고 손 바꾸기·큰 역회전·중심을 가로질러 각도를 누적하는 동작은 다시 시작한다.

회전 이미지의 원형 중심축을 카메라 화면 (50%,50%)에 맞추고 노란 손잡이는 그 오른쪽에서 시작한다. 카메라 새 창/룰렛 전체화면은 우측 끝 PiP 모양/전체화면 아이콘으로 표시하며 평상시 안내 문장은 숨긴다. 버튼 설명은 접근성 이름과 툴팁으로 제공한다.

확대 시작은 회전 후 2600ms이며 확대·원판·확대 원판·제목 페이드가 같은 Web Animation 시계에서 실행된다. 타이머 지연이 확대를 늦추지 않으며 감속 중 확대 후 경계 흔들림으로 이어진다.
