# Motion Roulette

등수별 상품과 개수를 입력하면 남은 개수에 맞춰 원판이 바뀌는 경품 룰렛의 화면 초안이다. 설계 화면에서 만든 원판이 추첨 화면에서도 그대로 돌아간다.

## 실행

저장소 폴더에서 다음 명령을 실행한 뒤 브라우저에서 [로컬 화면](http://127.0.0.1:4173/)을 연다. Python 3가 필요하며 별도 빌드 과정은 없다.

```sh
python -m http.server 4173 --bind 127.0.0.1
```

## 초안 사용하기

1. 설계 화면에서 등수별 상품명과 개수를 입력하고 원판 미리보기를 확인한다.
2. 룰렛 돌리기 화면으로 이동해 참가자 이름을 입력한다.
3. 동작 따라 하기나 룰렛 돌리기 안내를 확인한 뒤 시연 버튼으로 시작한다.
4. 포인터가 멈춘 상품과 참가자 이름을 확인하고 다음 회차로 넘어간다. 당첨 상품의 남은 수량은 하나 줄어든다.

카메라 영역은 동작 안내와 인식 진행을 보여 주는 시뮬레이션이다. 현재 초안은 카메라 영상을 수집하지 않으며, 실제 손·팔 동작 인식은 후속 구현 단계다. 상품과 추첨 데이터는 사용 중인 브라우저에서 처리하고 서버로 보내지 않는다.

## 검증

계산 로직 테스트는 Node.js에서 `node --test tests/roulette.test.cjs`로 실행한다. 별도 패키지 설치는 없다. 화면별 동작과 검증 범위는 [화면 초안](docs/wireframes.md), [검증 기록](docs/verification.md)에 정리했다.

초안에서 구현한 기능: 상품 추가·삭제, 수량 기반 미리보기, 두 모션 안내 시연, 수동 회전, 당첨 팝업, 재고 차감, 기록, 자동 저장과 중단 회차 복구. 실제 모션 인식, 색상 직접 변경, 설정 파일 가져오기/내보내기, CSV, 1등 연출 기능, 배포는 다음 단계다.
