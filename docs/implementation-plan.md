# 모션 룰렛 구현 계획 v0.6

2026-11-09 · 실제 카메라 연결과 인터페이스 개선 반영. v0.3의 이름 입력과 시뮬레이션 계획은 아래 최신 범위로 대체한다.

## 요구사항

- 등수별 상품명·수량으로 원판과 확률 자동 구성.
- 참가자 이름 입력 제거. 원판·선물 목록·카메라 중심 화면.
- 카메라 영상 위 팔 위치, 안내 원과 인식 진행률 표시.
- 중앙 2초 확인 후 양손 들기 1초를 따라 하고, 이어서 한 손으로 시작점에서 한 바퀴 돌려야 시작. 하체가 보일 필요 없음.
- 마지막 상단 포인터 확대·작은 좌우 흔들림·정지 후 결과 발표. 확대 후 계속 한 방향으로 추가 회전하지 않음.
- 제목 학교안심 포스터, 나머지 케리스 배움체.
- 좌측 룰렛 이미지와 모션 룰렛 제목, 우측 A안 연구회 로고.

## 구현 파일

- `index.html`, `styles.css`: 두 화면과 폰트·PNG 안내 이미지.
- `app.js`: 무기명 회차, 결과·재고·저장·확대 연출.
- `roulette.js`: 수량 기반 확률·각도·양방향 정지 각도.
- `motion-camera.js`: 권한·영상·로컬 모델·오버레이·트랙 수명 관리.
- `motion-gestures.js`: 자세 유지·원호 판정, 추적 끊김과 중복 시작 방지.
- `assets/`: 폰트, 생성 이미지, 원본 A 로고, MediaPipe 엔진·모델·라이선스.
- `tools/serve.py`, `start-preview.cmd`: localhost 정적 실행기.

## 완료된 흐름

설계 → 카메라 연결 → 중앙 위치 2초 확인 → 상체 양손 자세 1초 → 같은 손으로 한 바퀴 → 약 4.1초 회전 → 상단 포인터 자리에서 약 2.4초의 경계 좌우 흔들림 → 정지 확인 0.45초 → 결과 → 확인 → 다시 2초 위치 확인.

상품 추첨은 남은 개수의 가중치로 결정한다. 선택된 조각의 진입 경계 안쪽에 안전 여유를 두어 정지하고, 원판과 확대창은 같은 각도를 사용한다. 방향은 제스처를 따르며 확률은 동일하다. 애니메이션 감소 설정에서는 짧게 회전하고 확대를 생략한다.

회차별 결과와 남은 개수는 브라우저에 저장한다. 중단 회차를 같은 결과·정지 위치로 복구하며 한 번만 재고를 차감한다. 과거에 저장한 이름 포함 기록은 유지하고 신규 기록만 회차로 표시한다.

## 위험과 대응

영상 인식 실패에는 구체적 안내와 수동 시작을 제공한다. 저사양 환경에서는 추론을 약 10fps로 제한하고 회전 중 중지한다. 여러 사람·추적 끊김은 판정 진행을 초기화한다. 브라우저 저장 삭제·기기 변경·동시 여러 창 운영은 서버 없이 동기화하지 않는다.

최신 UI: 이름·동작 시작 버튼·원판 중앙 중복 아이콘 제거. 결과는 새싹 이미지·등수·상품명·확인. 로고 밝은 배경은 원본 보존 필터로 제거. 하단 저작권과 제작자 표기 추가.

시작 자세 네 가지(양손 높이 들기, 양손 어깨 가까이, 한 손 높이 들기, 양팔로 머리 위 큰 하트)를 회차별 순서로 안내한다. 각 자세 유지 1초 후 원호 동작으로 이어진다. 손가락 하트가 아니라 어깨·팔꿈치·손목으로 큰 팔 하트를 판정한다. 결과 이미지 1~10등은 별도 투명 PNG를 사용하고 11등 이상은 10등 이미지로 제한한다. 이 선택은 당첨 확률에 영향을 주지 않는다. 구현은 presentation.js와 motion-gestures.js에 분리했다.


## 카메라 피드백 후 조정

- 양손 어깨 가까이는 골반 추정 높이 대신 어깨 간격을 기준으로 허용 범위를 계산하여 조금 낮거나 구부러진 팔도 인정한다.
- 원 그리기는 AR 손잡이에 150ms 멈추어 잡은 뒤 같은 손을 편하게 한 바퀴(약300도부터 인정) 돌리면 완료한다. 반대 팔과 팔꿈치는 요구하지 않는다. 손 떨림·중심 가로지르기·다른 손으로 바꾸기는 완료로 세지 않는다.
- 손잡이를 잡은 뒤 원판이 손의 방향을 따라 미리 움직이며, 성공 시 그 각도에서 본 회전으로 연결된다. 확률은 바뀌지 않는다.
- 확대창은 접근 회전 종료 1500ms 전에 나타나 800ms 동안 커진다. 원판과 동일한 애니메이션 시계를 사용해 감속과 좌우 정착이 연속으로 보인다.
- 800px 이하 화면에서는 모션 완료 시 룰렛 영역으로 자연스럽게 스크롤한다.
- 추첨 화면 하단의 설계 화면 이동 링크는 삭제하고 상단 탭을 사용한다.


## 듀얼 모니터

추첨 화면의 카메라 새 창 버튼으로 같은 영상·관절 표시·AR 손잡이를 별도 창에 표시한다. 카메라 아래에 목표 동작 그림·설명·진행률이 표시되며 카메라 연결과 전체화면 버튼을 제공한다. 새 창을 다른 모니터로 옮기고 전체화면을 누른다. 원래 화면은 룰렛을 크게 보여 주며 룰렛 전체화면 버튼도 제공한다. 카메라 창을 닫으면 원래 배치로 복귀한다. 카메라와 모델은 한 번만 열고 새 창은 결과를 공유한다. 새 창의 프레임 시계로 추적을 계속하며 원래 탭을 닫으면 카메라 창도 닫는다. 브라우저 팝업 차단 시 허용 안내를 표시한다.


운영자 1등 모드: 연구회 로고·명칭 영역을 0.9초 이내 간격으로 연속 5번 누르면 배경이 옅은 붉은색으로 바뀐다. 활성 상태에서 한 번 더 누르면 취소된다. 실제 다음 추첨 한 회차에만 남아 있는 1등 상품을 선택하고 즉시 모드를 해제하며, 기존 감속·경계 확대·결과·재고 처리 경로를 그대로 사용한다. 1등 소진 시 활성화하지 않는다. 회전 중 클릭은 무시하며 새로고침하면 모드는 해제된다. 일반 모드의 수량 비례 추첨은 유지한다.


카메라 분리 창에도 본 화면의 결과 팝업과 동일한 등수별 캐릭터·등수·상품명을 표시한다. 회전 종료 후 본 화면 결과가 열릴 때만 함께 열며, 어느 쪽의 확인 버튼으로도 두 결과창을 함께 닫는다. 모바일 상단은 모션 룰렛과 연구회 로고·명칭을 작은 크기로 좌우 한 줄에 배치하고 탭은 다음 줄에 둔다. 손잡이 이미지의 원형 중심축은 카메라 정중앙이며 같은 손으로 한 바퀴를 완료해야 본 추첨이 시작된다.

팔 하트 판정은 골반 높이 대신 어깨 간격을 기준으로 한다. 이마 부근에서 손을 모으고 팔꿈치를 둥글게 벌린 모양을 유지하되, 양손 높이 차이·낮거나 높은 팔꿈치·일부 손목 신뢰도 저하를 허용한다. 손만 모은 손가락 하트나 가슴 앞 포즈는 구분한다. 한 바퀴 손잡이 동작은 반대 손이나 팔꿈치를 요구하지 않으며 최대 12초 안에 같은 방향 약300도를 누적한다. 작은 반경 변화는 허용하고 손 바꾸기·큰 역회전·중심을 가로질러 각도를 누적하는 동작은 다시 시작한다.

회전 이미지의 원형 중심축을 카메라 화면 (50%,50%)에 맞추고 노란 손잡이는 그 오른쪽에서 시작한다. 카메라 새 창/룰렛 전체화면은 우측 끝 PiP 모양/전체화면 아이콘으로 표시하며 평상시 안내 문장은 숨긴다. 버튼 설명은 접근성 이름과 툴팁으로 제공한다.

확대 시작은 회전 후 2600ms이며 확대·원판·확대 원판·제목 페이드가 같은 Web Animation 시계에서 실행된다. 타이머 지연이 확대를 늦추지 않으며 감속 중 확대 후 경계 흔들림으로 이어진다.

경계 연결 보정: 접근 곡선의 마지막 속도와 첫 오버슈트의 시작 속도를 동일한 양의 값(역방향은 음의 값)으로 맞춘다. 경계 자체에서는 정지하지 않고, 경계를 지나 첫 흔들림 극점에서만 속도가0이 되며 반대 방향으로 정착한다. animationFrames가 두 방향의 연결 속도를 계산한다. 브라우저 경계 전후16.7ms 간격 표본에서37.56→35.74→33.94→32.14→30.16→28.06→26.05→24.10도/초로 연속 감속했고 원판/확대각도 동기화 및 최종 당첨각 일치를 확인했다.


표시 방식: 설계 제목 옆의 중복 ‘추첨 화면으로’ 버튼을 제거한다. 미리보기 상단에서 크게 보기(grouped)와2배로 나눠 섞기(split)를 선택한다. split은 재고 비율을 유지하며 각 상품 조각을 절반 크기로 두 번, 서로 반대편에 배치한다. 저장 키wheelLayout은 기존 저장 데이터에 없으면grouped로 보완한다. 일반/운영자 당첨 상품 선택 후 실제 시각 조각 중 하나를 균등하게 골라 정지 각도를 계산한다. 기록과 재고는 상품 기준으로 한 번만 처리하며 중단 복구는 저장된 정지각이 속하는 시각 조각을 찾는다.


행사장 피드백 반영: 화면 밖으로 팔을 펴야 하는 T자 자세를 제거하고 양손을 각자 어깨 가까이에 올리는 자세(hands_near_shoulders)로 교체했다. 이 자세는 얼굴·어깨·양손만 확인하며 팔꿈치는 요구하지 않는다. 새 안내 PNG도 같은 캐릭터로 교체했다. 손잡이는 보통 기존 대비 약1.5배 커지고 먼 참가자에게도 최소 크기를 유지한다. 잡는 영역은 안내 반지름의75%, 유지150ms, 약300도부터 완주 인정, 최소4표본/250ms이며0.4초 빠른 회전도 허용한다. 반경15~320%, 작은 역방향 흔들림, 손목 가림250ms를 허용하고 잡은 손과 참여자 확인은 유지한다. 원호 인식 중에는 약20fps를 목표로 표본을 늘리고 자세 안내는 약10fps로 유지한다.


회차 내 모션 유지: 위치 확인2초 이후에는 pose/circle 상태를 추첨까지 유지한다. 인식 누락·다수 사람·긴 프레임 간격·몸 위치 변화·손목 누락 시 유효 시간/회전각을 보존하며 일시정지한다. 재인식 첫 표본의 각도 이동은 진행에 추가하지 않는다. 잘못된 포즈와 가려진 시간은 자세 유지 시간으로 세지 않는다. 회전 미리보기도 되감지 않는다. 기록 창은 중단 후 재개한다. 카메라 연결 옆 아이콘과 분리 창 아이콘으로 카메라/모델을 재시작하여 위치 확인부터 다시 진행할 수 있다. 재시작은 재고/기록을 수정하지 않으며 룰렛 회전 중에는 비활성화한다.


방향·몸 기준·글자 표시: 카메라 손잡이 둘레에 시계/반시계 방향 화살표를 표시하며, 움직임이 확인되면 선택한 방향만 남긴다. 분리 창에도 같은 오버레이를 공유한다. 몸의 기준 위치와 팔 들기 높이는 골반 여부와 무관하게 코·양어깨에서 산출한다. 설계 화면의 글자 표시(크게/작게/등수만)는 자동 저장되어 미리보기·추첨·확대에 함께 적용된다. 글자는 실제 시각 조각의 크기에 맞춰 축소하며 좁은 조각에는 등수만 표시한다. 텍스트는 조각 안의 안전 영역으로 제한해 이웃 칸에 겹치지 않게 한다. 수량·당첨 확률·기록에는 영향을 주지 않는다. 기존 저장에는 글자 표시를 크게로 보완한다.


자유 휘두름: MotionFlow의 유지 모드에 손 궤적 기반 판정을 추가했다. 안내 원 중심 대신 최근 실제 손 경로의 경계 상자 중심으로 방향성 있는 회전을 측정한다. 넓이·높이·관측 이동 거리·관측 회전각·시작점 부근 복귀·면적을 함께 확인하여 치우친 타원이나 모서리 있는 큰 회전을 허용한다. 손이 사라진 연결 구간은 거리/각도에 더하지 않고 진행률은 보존한다. 가림으로 여러 관측 구간으로 나뉜 경우 거리 조건에 여유를 준다. 재인식 첫 표본이나 정지 상태만으로는 완료하지 않는다. 기존 각도 판정도 보조로 유지하며 새 회차/수동 새로고침 시 경로를 비운다.
