# 모션 룰렛 구현 계획 v0.6

2026-11-09 · 실제 카메라 연결과 인터페이스 개선 반영. v0.3의 이름 입력과 시뮬레이션 계획은 아래 최신 범위로 대체한다.

## 요구사항

- 등수별 상품명·수량으로 원판과 확률 자동 구성.
- 참가자 이름 입력 제거. 원판·선물 목록·카메라 중심 화면.
- 카메라 영상 위 팔 위치, 안내 원과 인식 진행률 표시.
- 중앙 2초 확인 후 양손 들기 1초를 따라 하고, 이어서 한 손으로 시작점에서 한 바퀴 돌려야 시작. 하체가 보일 필요 없음.
- 마지막 상단 포인터 확대·작은 좌우 흔들림·정지 후 결과 발표. 확대 후 계속 한 방향으로 추가 회전하지 않음.
- 제목 학교안심 포스터, 나머지 케리스 배움체.
- 좌측 룰렛 이미지와 모션 룰렛 제목, 우측 A안 연구회 로고.

## 구현 파일

- `index.html`, `styles.css`: 두 화면과 폰트·PNG 안내 이미지.
- `app.js`: 무기명 회차, 결과·재고·저장·확대 연출.
- `roulette.js`: 수량 기반 확률·각도·양방향 정지 각도.
- `motion-camera.js`: 권한·영상·로컬 모델·오버레이·트랙 수명 관리.
- `motion-gestures.js`: 자세 유지·원호 판정, 추적 끊김과 중복 시작 방지.
- `assets/`: 폰트, 생성 이미지, 원본 A 로고, MediaPipe 엔진·모델·라이선스.
- `tools/serve.py`, `start-preview.cmd`: localhost 정적 실행기.

## 완료된 흐름

설계 → 카메라 연결 → 중앙 위치 2초 확인 → 상체 양손 자세 1초 → 같은 손으로 한 바퀴 → 약 4.1초 회전 → 상단 포인터 자리에서 약 2.4초의 경계 좌우 흔들림 → 정지 확인 0.45초 → 결과 → 확인 → 다시 2초 위치 확인.

상품 추첨은 남은 개수의 가중치로 결정한다. 선택된 조각의 진입 경계 안쪽에 안전 여유를 두어 정지하고, 원판과 확대창은 같은 각도를 사용한다. 방향은 제스처를 따르며 확률은 동일하다. 애니메이션 감소 설정에서는 짧게 회전하고 확대를 생략한다.

회차별 결과와 남은 개수는 브라우저에 저장한다. 중단 회차를 같은 결과·정지 위치로 복구하며 한 번만 재고를 차감한다. 과거에 저장한 이름 포함 기록은 유지하고 신규 기록만 회차로 표시한다.

## 완료 판정과 검증

- 수량 1:3:6은 10/30/60% 및 36/108/216도.
- 방향과 관계없이 포인터가 확정된 조각 안에 정지.
- 목표 자세가 1초 유지되거나 유효 원호가 완성될 때 한 번만 시작.
- 추적 끊김·직선 이동·손 교체·다인 감지에는 진행 초기화.
- 모달을 열면 인식 중지, 설계 이동·탭 숨김·페이지 이탈 시 카메라 종료.
- 최종 확대가 끝나기 전에는 당첨 모달을 열지 않음.

- 320/390/768/1024/1440px 두 화면 가로 넘침 없음.
- 단위·수명 주기 테스트 30개와 브라우저 연결 검증 통과. 세부는 verification.md.

## 다음 단계

실물 카메라와 현장 조명에서 전체 순서의 성공률·오시작·지연을 측정한다. 현재는 실제 로컬 모델의 가상 카메라 분석과 좌표 기반 동작 연결까지 검증했다. 물리 카메라 인식률은 미측정이다.

1등 예약 연출, 색상 직접 편집, 설정/기록 내보내기, 소리와 공개 배포는 아직 구현하지 않았다. 여러 기기 재고 공유와 계정이 필요할 때 별도 백엔드/DB를 설계한다.

## 위험과 대응

영상 인식 실패에는 구체적 안내와 수동 시작을 제공한다. 저사양 환경에서는 추론을 약 10fps로 제한하고 회전 중 중지한다. 여러 사람·추적 끊김은 판정 진행을 초기화한다. 브라우저 저장 삭제·기기 변경·동시 여러 창 운영은 서버 없이 동기화하지 않는다.

최신 UI: 이름·동작 시작 버튼·원판 중앙 중복 아이콘 제거. 결과는 새싹 이미지·등수·상품명·확인. 로고 밝은 배경은 원본 보존 필터로 제거. 하단 저작권과 제작자 표기 추가.

시작 자세 네 가지(양손 높이 들기, 양팔 벌리기, 한 손 높이 들기, 양팔로 머리 위 큰 하트)를 회차별 순서로 안내한다. 각 자세 유지 1초 후 원호 동작으로 이어진다. 손가락 하트가 아니라 어깨·팔꿈치·손목으로 큰 팔 하트를 판정한다. 결과 이미지 1~10등은 별도 투명 PNG를 사용하고 11등 이상은 10등 이미지로 제한한다. 이 선택은 당첨 확률에 영향을 주지 않는다. 구현은 presentation.js와 motion-gestures.js에 분리했다.


## 카메라 피드백 후 조정

- 양팔 벌리기는 골반 추정 높이 대신 어깨 간격을 기준으로 허용 범위를 계산하여 조금 낮거나 구부러진 팔도 인정한다.
- 원 그리기는 AR 손잡이에 250ms 멈추어 잡은 뒤 같은 손을 한 바퀴(360도) 돌리면 완료한다. 반대 팔과 팔꿈치는 요구하지 않는다. 손 떨림·중심 가로지르기·다른 손으로 바꾸기는 완료로 세지 않는다.
- 손잡이를 잡은 뒤 원판이 손의 방향을 따라 미리 움직이며, 성공 시 그 각도에서 본 회전으로 연결된다. 확률은 바뀌지 않는다.
- 확대창은 접근 회전 종료 1100ms 전에 나타나 650ms 동안 커진다. 원판과 동일한 애니메이션 시계를 사용해 감속과 좌우 정착이 연속으로 보인다.
- 800px 이하 화면에서는 모션 완료 시 룰렛 영역으로 자연스럽게 스크롤한다.
- 추첨 화면 하단의 설계 화면 이동 링크는 삭제하고 상단 탭을 사용한다.


## 듀얼 모니터

추첨 화면의 카메라 새 창 버튼으로 같은 영상·관절 표시·AR 손잡이를 별도 창에 표시한다. 카메라 아래에 목표 동작 그림·설명·진행률이 표시되며 카메라 연결과 전체화면 버튼을 제공한다. 새 창을 다른 모니터로 옮기고 전체화면을 누른다. 원래 화면은 룰렛을 크게 보여 주며 룰렛 전체화면 버튼도 제공한다. 카메라 창을 닫으면 원래 배치로 복귀한다. 카메라와 모델은 한 번만 열고 새 창은 결과를 공유한다. 새 창의 프레임 시계로 추적을 계속하며 원래 탭을 닫으면 카메라 창도 닫는다. 브라우저 팝업 차단 시 허용 안내를 표시한다.


운영자 1등 모드: 연구회 로고·명칭 영역을 0.9초 이내 간격으로 연속 5번 누르면 배경이 옅은 붉은색으로 바뀐다. 활성 상태에서 한 번 더 누르면 취소된다. 실제 다음 추첨 한 회차에만 남아 있는 1등 상품을 선택하고 즉시 모드를 해제하며, 기존 감속·경계 확대·결과·재고 처리 경로를 그대로 사용한다. 1등 소진 시 활성화하지 않는다. 회전 중 클릭은 무시하며 새로고침하면 모드는 해제된다. 일반 모드의 수량 비례 추첨은 유지한다.


카메라 분리 창에도 본 화면의 결과 팝업과 동일한 등수별 캐릭터·등수·상품명을 표시한다. 회전 종료 후 본 화면 결과가 열릴 때만 함께 열며, 어느 쪽의 확인 버튼으로도 두 결과창을 함께 닫는다. 모바일 상단은 모션 룰렛과 연구회 로고·명칭을 작은 크기로 좌우 한 줄에 배치하고 탭은 다음 줄에 둔다. 손잡이 시작점은 카메라 중앙이며 같은 손으로 한 바퀴를 완료해야 본 추첨이 시작된다.

팔 하트 판정은 골반 높이 대신 어깨 간격을 기준으로 한다. 이마 부근에서 손을 모으고 팔꿈치를 둥글게 벌린 모양을 유지하되, 양손 높이 차이·낮거나 높은 팔꿈치·일부 손목 신뢰도 저하를 허용한다. 손만 모은 손가락 하트나 가슴 앞 포즈는 구분한다. 한 바퀴 손잡이 동작은 반대 손이나 팔꿈치를 요구하지 않으며 최대 12초 안에 같은 방향 360도를 누적한다. 작은 반경 변화는 허용하고 손 바꾸기·큰 역회전·중심을 가로질러 각도를 누적하는 동작은 다시 시작한다.
