# 화면 초안 검증 기록

2026-11-09 · 로컬 Chromium 브라우저와 Node.js. 공개 배포 및 실제 카메라 검증은 수행하지 않음.

## 통과

- `node --check app.js`, `node --check roulette.js`: 구문 오류 없음.
- `node --test tests/roulette.test.cjs`: 4개 통과. 수량 기반 각도/확률, 경계 난수 선택, 재고 소진 제외, 포인터 정지 각도.
- 상품 개수 변경 시 총 수량·확률·원판 즉시 반영.
- 이름 없이 시작 시 입력 안내와 초점 이동.
- 두 모션 방식 전환 시 안내 그림과 문구가 함께 전환.
- 모션 성공 시연 → 회전 → 당첨 팝업 → 기록 1건·재고 1개 반영.
- 회전 중 시작 버튼 비활성화.
- 입력 중 개수가 비어 있을 때 행사명을 변경해도 마지막 유효 설정과 당첨 기록 보존.
- 중단된 회차 복구 시 같은 결과·정지 각도를 복원하고 재고 한 번만 차감.
- 마지막 1개 지급 후 추가 추첨 비활성화. 새로고침 후에도 당첨 기록 열람 가능.
- 너비 320/390/768/1024/1440px의 두 화면, 총 10개 배치에서 문서 가로 넘침 없음.
- 1440px 데스크톱 및 390px 모바일 캡처를 열어 배치와 텍스트 확인.
- 애니메이션 감소 설정에서 회전 시간을 단축한 상태로 마지막 상품 흐름 검증.
- 검증 중 브라우저 콘솔 오류·경고 0건.

## 한계

- 촬영, 손·팔 추적, 목표 자세/원호 판정은 미구현. 화면의 동작 진행률은 시연 버튼으로 구동.
- 실물 카메라·프로젝터·Safari 및 모바일 실기기 검증은 후속 단계.
- 자동 저장은 현재 브라우저 기기에 한정. 여러 창에서 같은 행사를 동시에 진행하는 동기화는 범위 밖.
- 웹 접근성 전체 자동/수동 감사는 미실시. 초점 표시, 입력 라벨, 결과 대화상자 이름, 색상 외 텍스트 안내, 애니메이션 감소 대응을 구현.
- 회원 계정, 서버 감사 추첨, CSV/JSON 내보내기, 색상 직접 편집, 1등 연출과 사운드 기능은 미구현.

브라우저 검증 도구와 캡처는 개발 산출물로 구분하며 앱에는 외부 패키지 의존성을 추가하지 않았다.
