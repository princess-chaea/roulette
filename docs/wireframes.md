# 현재 화면 구성

2026-11-09 · 실제 카메라 연결판. 이름 입력칸은 제거했다.

## 설계 #setup

좌측 상품명·수량 편집, 동작 방식, 행사명. 우측 실시간 원판과 확률. 상품 수량 변경 시 바로 반영한다. 원판 자체는 같은 컴포넌트로 추첨에서도 회전한다.

## 추첨 #draw

PC 왼쪽은 큰 원판과 상품명·남은 개수의 선물 카드, 오른쪽은 넓은 카메라 화면과 동작 안내다. 모바일에서는 이 세 주요 영역을 세로 배치한다.

카메라 연결 전에는 새싹 캐릭터 동작 이미지를 표시한다. 연결 후에는 실제 거울 영상과 관절/원 오버레이, 작은 목표 동작 이미지를 함께 표시한다. 카메라 연결과 동작 인식 시작은 별도 버튼이다.

따라 하기: 양손을 머리 위로 올리고 1초 유지. 돌리기: 화면 오른쪽 노란 시작점에 한 손을 0.25초 둔 뒤 같은 손으로 반 바퀴 이동. 성공 시 한 번만 원판이 돈다.

마지막 감속에는 실제 원판과 같은 각도로 움직이는 포인터 확대창을 표시한다. 완전 정지와 짧은 확인 시간 뒤 결과를 발표한다. 상품 재고와 기록을 반영하고 다음 회차는 인식을 다시 시작한다. 기록은 회차별이다.

## 브랜드와 폰트

좌측 모션 룰렛 제목과 룰렛 PNG, 우측 A안 초등정보교과교육연구회 원본 가로 로고. 제목 학교안심 포스터 B, 나머지 케리스 배움체 R/B. [디자인 기준](../DESIGN.md)을 따른다.
