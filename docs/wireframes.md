# 화면 초안 01

2026-11-09 · 상호작용 가능한 HTML/CSS/JavaScript 초안. 실제 카메라 인식과 배포는 후속 단계.

## 설계 화면 `#setup`

- 상단: 모션 룰렛 브랜드, 설계/돌리기 탭, 화면 초안 표시.
- 제목: 우리만의 행운을 설계해요. 우측에 추첨 화면 이동 버튼.
- 왼쪽: 등수·상품명·개수 입력, 상품 추가/삭제, 동작 방식 선택, 행사명.
- 오른쪽: 원판과 고정 포인터, 등수별 상품 목록과 확률. 수량 변경 즉시 반영.
- 모바일: 입력 카드 다음에 미리보기 카드 배치. 상단 이동 버튼은 전체 너비.
- 초기 예시: 1등 1개, 2등 3개, 3등 6개, 4등 10개. 총 20개.
- 신규 행을 추가하면 다음 등수를 자동 부여. 삭제 시 현재 행 순서로 등수를 다시 붙임. 저장된 과거 당첨 등수는 유지.
- 0개 행은 설정에는 남기고 원판에서 제외. 첫 버전은 색상을 자동 지정.

## 돌리기 화면 `#draw`

- 왼쪽: 큰 원판, 고정 포인터, 남은 상품 수, 회전 상태와 경품 개수.
- 오른쪽: 참가자 이름, 모션 방식 탭, 안내 그림, 진행 게이지, 시연 시작 버튼.
- 따라 하기: 양팔을 위로 든 안내 그림과 손/팔 관절 위치 표현.
- 돌리기: 원형 궤적·회전 화살표·손 그림.
- 카메라 영역에는 '시뮬레이션', '카메라 연결 전 · 화면 시안'을 명시.
- 시연 버튼은 모션 성공 진행률을 채운 다음 원판을 회전. 수동 시작도 제공.
- 이름 없이 시작하면 입력 안내 후 이름 칸에 초점 이동.
- 회전 중 중복 시작·이름 변경·화면 전환 차단.
- 당첨 팝업에 이름·등수·상품명 표시. 기록 1건과 해당 상품 1개 차감.
- 팝업을 닫으면 다음 참가자 준비. 이때 남은 수량으로 원판 재구성.
- 우측 상단 당첨 기록은 모달로 열림. 상품 소진 후에도 열람 가능.
- 모바일: 원판 → 이름 → 모션 안내 순서. 주요 영역을 숨기지 않고 세로 배치.

## 시각 기준

크림색 배경, 짙은 초록 글자와 버튼, 라임색 시작 버튼, 코럴·노랑·청록·보라 원판. 화면별로 같은 원판과 컴포넌트를 재사용한다. 세부 기준은 [DESIGN.md](../DESIGN.md)를 따른다.

## 후속 단계

실제 영상·손/상체 인식을 연결하기 전에 거리·조명·다인 환경에서 인식 기술 실험을 진행한다. 현재 진행률과 관절 표시는 시연 UI이며 실제 분석 결과가 아니다.
